KAROO FARMING TRANSPORT WEBSITE

1. EXTRACT the zip first (right-click > Extract All). Do NOT open index.html from inside the zip.
2. Double-click index.html to preview in your browser.
3. To publish, upload the whole folder contents to your hosting (public_html).

Pages: index.html, about.html, services.html, fleet.html, contact.html
Each page already contains its own styling and scripts, so it works even if opened on its own.
The css/ and js/ folders hold the same code in editable form.
Photos live in assets/img/ (keep that folder next to the HTML files).
WhatsApp number: WA_NUMBER at the top of js/main.js (also inside each HTML page).
